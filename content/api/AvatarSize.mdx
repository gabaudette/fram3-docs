# AvatarSize

Predefined size steps for an Avatar. The pixel value of each step is derived from the active theme's Spacing token at render time.

## Fields

### Large

Large avatar — 7× theme spacing (56 px at default spacing).

### Medium

Medium avatar — 5× theme spacing (40 px at default spacing). Default.

### Small

Small avatar — 4× theme spacing (32 px at default spacing).
