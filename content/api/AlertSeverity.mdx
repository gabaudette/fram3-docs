# AlertSeverity

The visual severity of an Alert, which controls the accent color applied to the left border and title.

## Fields

### Error

An error or destructive action. Uses the theme's error color.

### Info

Informational message. Uses the theme's primary color.

### Success

Operation succeeded. Uses a green accent.

### Warning

Something may need attention. Uses an amber accent.
